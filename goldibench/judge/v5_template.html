每题给出三张图：原图（START）、客户要的效果（TARGET）和一位修图师交来的结果（CANDIDATE）。TARGET 和 CANDIDATE 都是从 START 修改出来的。请像验收工作那样判断：CANDIDATE 是否做出了 TARGET 的效果。

  1. 是否达到：把 CANDIDATE 交给要 TARGET 的客户，能不能算完成。细小的、要仔细对比才看得出的差别不算没达到。
  2. 差别：和 TARGET 相比，CANDIDATE 改得不够、基本一致、过头，还是改的方向或风格不同；如果几乎和 START 一样，选"基本没改"。
  3. 图片有照片，也有矢量图和三维渲染，判断标准相同。
  4. 拿不准就选"不确定"，不要猜。点击图片可以放大。
  5. 答案自动保存，可以随时离开，回来后从上次的位置继续。全部完成后点"提交"。
